## Reflexão

O Checkstyle detetou corretamente o método com nome inválido (`Calcular_Pontos`), provando que a integração com o GitHub Actions e o Maven está a funcionar corretamente. 

A ferramenta não consegue avaliar a semântica dos nomes (ou seja, se o nome `calcularPontos` faz sentido para a função que o método desempenha), limitando-se a verificar a sintaxe (letras maiúsculas/minúsculas, underscores, etc.). Além disso, exige que o projeto tenha o plugin do Maven configurado no `pom.xml` para correr no GitHub Actions.
