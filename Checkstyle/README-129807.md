
# Checkstyle — Quality Gate

**Aluno:** LETI-129807  
**Projeto:** Battleship2  
**Convenção:** Nomes dos métodos Java (MethodName)

## Configuração

Foi configurado um workflow GitHub Actions com Checkstyle para verificar a convenção de nomes dos métodos Java.

A regra MethodName utiliza a expressão regular `^[a-z][a-zA-Z0-9]*$`, exigindo que os nomes comecem por uma letra minúscula e contenham apenas letras e números.

## Evidências

### Execução com falha

https://github.com/LETI-129807/Battleship2/actions/runs/42432754886/job/128585023153

Foi introduzido deliberadamente o método `Calcular_Pontos()` na classe `PdfExporter.java`. O Checkstyle identificou a violação da regra MethodName na linha 242 e o workflow falhou.

### Execução com sucesso

https://github.com/LETI-129807/Battleship2/actions/runs/42432965992

O método foi corrigido para `calcularPontos()`. Após a correção, o workflow terminou com sucesso.

## Reflexão

O Checkstyle permitiu identificar automaticamente uma violação da convenção de nomes, indicando o ficheiro e a linha onde ocorreu. A execução falhou com o nome inválido e passou após a correção, demonstrando o funcionamento do quality gate. Contudo, o Checkstyle não consegue avaliar se um nome é suficientemente claro, descritivo ou adequado à finalidade do método.
