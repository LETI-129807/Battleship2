# Qodana Gate (111591)

## Tabela de Mapeamento

| Cheiro (Fowler) | Inspeção no IDE | ID da inspeção | Métrica / limiar | Limitações |
| :--- | :--- | :--- | :--- | :--- |
| Long Method | Overly long method | `OverlyLongMethod` | LOC (Lines of Code) ≥ 16 | O IntelliJ/Qodana usa apenas um limite absoluto de linhas (LOC). A estratégia do livro exige combinar o tamanho (LOC) com a Complexidade Ciclomática (CYCLO), o que não é possível exigir em simultâneo (AND) nesta inspeção. |

## Reflexão

A ferramenta Qodana detetou corretamente o método longo que introduzi no código. Inicialmente, houve um falso positivo devido aos 203 avisos normais do projeto base, mas ao configurar o `failureConditions` para `any: 10000` e a severidade do `OverlyLongMethod` para `ERROR`, o gate passou a falhar apenas quando o cheiro estava presente.

A sensibilidade aos valores-limite é alta: se o limite for muito alto, o cheiro não é detetado. A principal limitação face à estratégia do livro é que o Qodana avalia apenas as linhas de código (LOC), não combinando com a Complexidade Ciclomática (CYCLO), como sugerido na teoria.
