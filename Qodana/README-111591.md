## Reflexão (Ponto 11)

A ferramenta Qodana detetou com sucesso o método longo que introduzi propositadamente. Inicialmente, houve um falso positivo/ruído causado por outros 203 avisos do projeto base, mas ao configurar o `failureConditions` para focar na severidade ERROR do `OverlyLongMethod`, o gate passou a falhar apenas quando o cheiro estava presente. 
A sensibilidade aos valores-limite é alta: se aumentarmos o `m: 16` para um valor superior, o método de teste de 20 linhas deixaria de ser detetado. 
A principal limitação face à estratégia do livro é que o Qodana usa limites absolutos (apenas LOC), enquanto o livro exige a combinação de LOC e Complexidade Ciclomática (CYCLO) para uma deteção mais precisa.
